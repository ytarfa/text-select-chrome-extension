# Privacy Policy: Text Select Highlighter

_Last updated: 3 November 2026_

Text Select Highlighter does not collect, store, transmit or sell any personal data.

- **Page content.** To find matches, the extension reads the text of the page you are viewing and the text you select. This happens entirely on your device. Page content is never stored or sent anywhere.
- **Settings.** Your preferences (case sensitivity, whole-word matching, minimum length, colour, opacity, style and badge visibility) are saved with Chrome's `storage.sync` API. If you're signed in to Chrome with sync turned on, Chrome syncs them between your browsers. The developer has no access to them.
- **No network requests.** The extension makes no network requests, uses no analytics and loads no remote code.

If you have questions, open an issue at https://github.com/ytarfa/text-select-chrome-extension/issues.
